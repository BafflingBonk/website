Use it in Aseprite

  1. Download the palette file.
  2. In Aseprite's palette panel, open the options menu (the three lines above the swatches) and choose Load Palette.
  3. For pixel art, switch the sprite to Sprite → Color Mode → Indexed, so every pixel stays one of these colours.
